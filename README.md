# Blue Boy - 2D Java RPG Game

This project is a 2D action-adventure RPG game developed using Java. It serves as a practical implementation of game development principles, including game loops, collision detection, and layer rendering.

## Project Overview
This project was developed by following the 2D RPG tutorial series by **ReSnow**. 
* **Focus:** Learning how to manage game entities, rendering layers, and handle complex game logic in Java.
* **Tech Stack:** Java Standard Library.

## Features
* **Player Movement:** Smooth 8-directional movement with custom animations.
* **Collision Detection:** Solid tile-based collision system.
* **Interactive World:** Objects like keys, chests, and doors with functional logic.
* **Rendering:** Layered rendering system to manage depth and perspective.
